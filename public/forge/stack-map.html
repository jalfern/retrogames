Known pattern, unusual build

The architecture is the same shape as GitHub's Copilot coding agent, OpenAI Codex or Cursor's background agents: assign an issue, get a PR. What's less common here:

Mostly local models

Qwen on oMLX across a Mac Studio and Mac minis does most of the work. Frontier models join as specialists or guests.

Self-governing rules

A 2-hour red-main clock, owned quarantines, a merge freeze, a trust gate and questions that time out to a default. The factory runs overnight without a person.

Proof over vibes

Mutation-proven checks, golden traces, and native ports verified against the web game across hundreds of thousands of ticks.

Model-agnostic lanes

Qwen, Gemini, Claude and Inkling are interchangeable workers on one protocol, which also makes them easy to compare.

In one line: a multi-agent software factory with GitHub as its blackboard, run mostly on local models, with a human setting taste.
