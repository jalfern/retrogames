# PICK RUSH dataset (#2734) — labelled grasp-and-place episodes

Generated by `npm run pickrush-export` (= `node scripts/pickrush-export.mjs`).
Deterministic: same commit + same seeds → byte-identical files.

## What a run is
Each seed is the REAL authored line: both cranes run `planner()` — the game's
own crane law without its seeded habits (no aim jitter, no skips, no RNG
draws; a pad stream cannot carry RNG through replay, so the corpus brain is
RNG-free by law). Every episode is banked through the #1141 Plaicraft kit
(`retrogames-rec/v1` + `episode` block) and replayed against the sim by
`verifyRecording` — hash match at every checkpoint or the export exits red.

## Files
- `episodes.jsonl` — one episode per line (20 seeds: practice 0..11,
  held-out 100..107 — the #1625 split discipline). Each carries per-tick
  pads for both seats, checkpoint hashes, and the label track (see
  `src/utils/robot/episode.js`).
- `drops.jsonl` — one row per drop:
  `{ s, game, t, kind, seat, outcome, why, bin?, pts? }` — `outcome` is
  `hit` (the tagged bin caught it — the sim's own judging law) or `miss`
  (wrong bin / shattered glass / slipped jaws). Pieces that rode off the
  belt untouched are not drops and carry no row.
- `summary.json` — corpus verdict: seeds, hit/miss totals, contracts won,
  `verifiedAll`, per-seed stats. Small enough to commit; the JSONL do not
  (they regenerate from seed).

## Honesty
The planner never mis-bins or slams glass, so the corpus misses are
barrel slips only (`why: slip`) — an accurate profile of a precise model
at rotating cargo, not a bug. Human takes banked in-browser (the live game
records every shift) carry the full `wrong`/`shatter` mix and live in
localStorage under `retrogames-episodes`, exportable through the kit's
`exportEpisodes()`.

Since #2742 the per-seed `score` includes PERFECT SHIFT payouts (the
whistle pays any seat whose shift carried no miss/wrong/shatter/floor).
Every seed banks exactly +500: shift 2 is the miss-free stretch of the
authored line, and both planner seats clear it clean (250 × 2). Drop
counts are untouched (the payout is scoring, not mechanics) — but the
checkpoint hashes in `summary.json` are #2742 hashes: regenerate the
corpus whenever the sim law changes, never hand-edit.
